# Biodome project report (LaTeX)

- `main.tex` is the whole report: two-column A4, with TikZ diagrams for the automata, the menu and the LCD screens.
- `figures/` holds the images (slides, diagrams, hardware).

## Compile
- Tectonic: `tectonic main.tex`
- TeX Live: `pdflatex main.tex` twice (the second run fills in the table of contents)
- Overleaf: upload this folder as a zip, then click Recompile.
